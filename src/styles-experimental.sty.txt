{-----COMMENT
This file defines visual style templates used for image generation.
Each template consists of three descriptive "slices" that guide the AI in creating the final image.
Every style starts with a header line formatted as: ">>> STYLE_NAME".

Each style block is enclosed between "{-----" and "-----}". Inside, the content is divided into three slices,
separated by lines of six hyphens ("------"). These slices represent different aspects of the generation process:

  1. VISUAL STYLE (First Slice): Defines the core visual appearance of the final image. This slice has the
     strongest influence on the output and sets the overall aesthetic.

  2. COMPOSITION & LIGHTING (Second Slice): Describes the composition, camera angles, and lighting conditions.
     While it doesn't directly alter the final image as much as the first slice, it introduces creative variation.
     The contrast between this slice and the first one encourages the model to be more imaginative.

  3. FINE DETAILS (Third Slice): Details how smaller elements, textures, and specific features will be rendered.
     It has a minimal impact on the overall image, allowing it to explore directions that may differ from the
     first slice without disrupting the core style.

Formatting Guidelines:
- Each slice typically begins with "YOUR CONTEXT:" followed by a bulleted list.
- Sentences usually start with "You" or "Your", but this is not strictly required.
- Sentences should have a maximum of approximately 120 characters.
- Maintaining this structure ensures consistency across all generated styles.

Placeholder:
- The <!-- {$@} --> marker at the end of each block is replaced by the user's prompt, which includes the
  scene, characters, and/or elements to be featured in the final image.
