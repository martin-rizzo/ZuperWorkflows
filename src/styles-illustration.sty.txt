This file defines multiple visual styles, each containing three "slices" of
descriptive text. Each style starts with a header line formatted as:
">>> STYLE_NAME".

Each style block opens with "{-----" and closes with "-----}". Inside, the text
is divided into three slices, separated by lines of six hyphens ("------"). These
slices correspond to different processing stages:
  - El primer slice marca el estilo final que tendra la imagen
  - El segundo slice intenta marcar la composición y el nivel de iluminación (afecta menos a la imagen final)
  - El tercer slice marca como se dibujaran los detalles fines aunque practicamente no afecto a la imagen final.

-----}
